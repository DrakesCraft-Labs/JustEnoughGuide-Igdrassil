# JustEnoughGuide (JEG)

Addon de **Slimefun 4** que rediseña y potencia la guía visual de Slimefun, implementando **búsqueda instantánea en tiempo real (RTS), sistema de marcadores personales y navegación multipágina optimizada**. Portado y adaptado por **DrakesCraft Labs** para Paper/Purpur 1.21.11 en Java 21.

---

## 🎯 Objetivo

Mejorar drásticamente la usabilidad y rapidez al consultar recetas en servidores con más de 40 addons instalados, eliminando la lentitud del libro vanilla tradicional mediante búsquedas instantáneas y favoritos.

---

## ⚡ Características Principales

- **Búsqueda en Tiempo Real (Real-Time Search)**:
  - Búsqueda dinámica de ítems y recetas sin necesidad de escribir el nombre completo.
- **Sistema de Marcadores y Favoritos**:
  - Los jugadores pueden guardar recetas frecuentes en una barra de acceso rápido persistente.
- **Diseño Visual Multipágina**:
  - Interfaz modular con soporte para visualizar grandes cadenas de crafteo complejas.
- **Traducción Depurada**:
  - Textos de interfaz y configuración adaptados al español.
